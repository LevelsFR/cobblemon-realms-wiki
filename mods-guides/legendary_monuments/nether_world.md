# 🔥🏗️ Legendary Structures of the Nether

## 🌋 Heatran Cave

{% hint style="info" %}
<p align="center">
Structure used to obtain <strong>Heatran</strong>.
</p>
{% endhint %}

### 🧭 Quick Overview

- 🎯 Objective: obtain [Heatran](../../pokemons-guides/gen-list2/gen_4.md#heatran)
- 🗺️ Gameplay: exploration and summoning
- ⚠️ Difficulty: high
- 🎁 Loot: numerous chests, including a secret room

### 🧗 Features

- Massive Nether cavern
- Numerous dangerous monsters
- Large amount of chests to explore
- Secret room containing additional loot
- Pedestal used to summon [Heatran](../../pokemons-guides/gen-list2/gen_4.md#heatran)

### 🌍 Generation

- 📌 Dimension: Nether
- 🏗️ Can generate anywhere in the Nether

***

## 🏛️ Treasures of Ruin Shrines

{% hint style="info" %}
<p align="center">
Structures used to obtain <strong>Wo-Chien</strong>, <strong>Chien-Pao</strong>, <strong>Ting-Lu</strong>, and <strong>Chi-Yu</strong>.
</p>
{% endhint %}

### 🧭 Quick Overview

- 🎯 Objective: obtain the Four Ruinous Pokémon  
- 🗺️ Gameplay: exploration and stake collection  
- ⚠️ Difficulty: medium  
- 🎁 Loot: none  

### 🧗 Features

- Each shrine is dedicated to a Legendary Pokémon.
- To activate it, you must first collect the **8 Stakes** corresponding to the shrine.
- Stakes can appear in any Nether biome.

### 🌍 Generation

- 🍃 **Grasswither Shrine** → Summons **[Wo-Chien](../../pokemons-guides/gen-list2/gen_9.md#wo-chien)** → 🌳 Warped Forest
- 🧊 **Icerend Shrine** → Summons **[Chien-Pao](../../pokemons-guides/gen-list2/gen_9.md#chien-pao)** → 🪨 Basalt Deltas
- 🎭 **Groundblight Shrine** → Summons **[Ting-Lu](../../pokemons-guides/gen-list2/gen_9.md#ting-lu)** → 💀 Soul Sand Valley
- 🔥 **Firescourge Shrine** → Summons **[Chi-Yu](../../pokemons-guides/gen-list2/gen_9.md#chi-yu)** → 🌋 Nether Wastes
