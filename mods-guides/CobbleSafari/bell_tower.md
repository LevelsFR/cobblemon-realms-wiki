# 🔔 Bell Tower | Ho-Oh Challenge

{% hint style="info" %}
<p align="center">Ascend a towering, multi-floor dungeon inspired by Johto, face the <strong>Ho-Oh</strong> boss and discover unique phoenix-themed rewards.</p>
{% endhint %}


## 🏯 The Climb

| Feature | Official 0.4 defaults |
| --- | --- |
| Tower | **11 floors**, approximately **155 blocks** tall |
| Progression | Ascend floor by floor, avoiding falls |
| Safety items | Rotom Phone Roto-Fall / Roto-Glide do **not** work here |
| Flight | Elytra gliding is disabled |
| Final encounter | **Ho-Oh** CSBoss near the top |

{% hint style="danger" %}
**Be careful with jumps:** both Elytra and the Rotom Phone's automatic fall-saving features are restricted in this dungeon. The run is intended to be a vertical traversal challenge.
{% endhint %}

## 🪜 Recommended Progression

{% stepper %}
{% step %}
### 1. Enter the Bell Tower instance
Locate a supported dungeon portal and enter the tower.
{% endstep %}
{% step %}
### 2. Climb to the next floor
Watch your footing, use the ramps and vertical structures and avoid falling back down.
{% endstep %}
{% step %}
### 3. Complete optional/assigned objectives
The 0.4.1 dimension can assign tasks for height gained, Lost Items, ramp jumps and boss participation.
{% endstep %}
{% step %}
### 4. Challenge Ho-Oh
Reach the upper arena and face **Ho-Oh**, which uses the CobbleSafari CSBoss system.
{% endstep %}
{% endstepper %}

## 🔥 Boss Battle and Rewards

Ho-Oh attacks with **Fire, Flying and jumping mechanics**. Stay mobile and watch the arena to survive the fight.

| Item | Description from the official release |
| --- | --- |
| **Phoenix Ashes** | Helps flowers grow much faster |
| **Phoenix Feather** | Saves the player near death and grants a stronger reborn state |

The 0.4.1 update also fixes the distribution of **Bell Tower Lost Item loot**. Do not assume that either item is guaranteed after a single run.
