# 📋 Motismart Holo-Skins List

{% hint style="info" %}
<p align="center">This page lists the different <strong>Holo-Skins</strong> available in <strong>CobbleSafari</strong>, as well as their appearances and the different methods for unlocking them.</p>
{% endhint %}

## 💻 How It Works

- 🔓 **Individual Unlock** - Holo-Skins are unlocked **individually for each player** and remain permanently unlocked. You therefore keep them even after creating a new Motismart.

- ⚡ **Instant Change** - Equipping a Holo-Skin is **completely free and instantaneous**. Open the Holo-Skin app, choose the one you like, and enjoy it immediately. You can change your appearance at any time, without any restrictions.

- 🎨 **Interface Customization** - Some Holo-Skins feature a **custom wallpaper** and a matching interface color. Do you prefer the skin's appearance but not its wallpaper? Simply disable the **Custom Wallpaper** option to restore the default wallpaper.

- ✨ **Shiny Motismart** - Motismart manufactured from a **Shiny Rotom** retain their unique appearance. Some Holo-Skins therefore have a **dedicated Shiny version**, specially adapted for these phones.

## 🔓 How to Unlock Holo-Skins?

| Method | Details |
| :---: | :---: |
| **Rotom Questline** | Each day, Rotom allows you to randomly obtain a colored skin that you do not already own during your conversation with it. |
| **Daily Quest** | Hayley's repeatable daily quest can sometimes reward a random locked skin. If you already own all available skins, it will give you tickets instead. |
| **Unlock Item** | A consumable **Holo-Skins Unlock** ![](https://raw.githubusercontent.com/LevelsFR/cobblemon-realms-wiki/refs/heads/main/imgwiki/CobbleSafari/skins_motismart/unlock.png) allows you to unlock a specific skin. The **Complete Holo-Skins Unlock** ![](https://raw.githubusercontent.com/LevelsFR/cobblemon-realms-wiki/refs/heads/main/imgwiki/CobbleSafari/skins_motismart/unlock_all.png) allows you to unlock all skins. |
| **Advancement** | Some advancements can also allow you to unlock Holo-Skins. |
