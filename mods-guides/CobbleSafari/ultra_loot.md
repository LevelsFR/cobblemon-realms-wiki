# 🎁 Ultra Space Loot & Equipment

{% hint style="info" %}
<p align="center">Ultra Space contains distinct tools, weapons, armor sets, curiosities and plants introduced in CobbleSafari 0.4.0.</p>
{% endhint %}


## 🛡️ Equipment

| Item | What it does |
| --- | --- |
| **Ultra Recon Armor** | Full-set Elytra ability (if enabled) and additional protection during Ultra Warp Ride |
| **Glutton Armor** | Eating with the set grants Gluttonous bonuses depending on fullness |
| **Stacked Shield** | Blocks damage and grants a boost, then needs to recharge |
| **Nihilhat** | Grants Conduit Power while in contact with water, with a strong hunger drawback |

## 🎯 Tools and Projectiles

| Item | Main use |
| --- | --- |
| **Needle Dart** | Fast projectile unaffected by gravity |
| **Harlequin Bomb** | Throwable random firework explosion |
| **Static Heap** | Can call lightning when it lands with no obstruction above |
| **Stellar Canon** | Gunpowder-powered smoke-signal launcher |
| **Origami Carrier** | Paper-powered launcher that fires decorative paper planes |

## 🌱 Special Plants

- **Beefy Seed** grows a Beefy Plant. Its fruit provides Strength, Resistance and Haste effects.
- **Beauty Seed** grows a Beauty Plant. Its fruit provides Invisibility, Speed and Jump Boost effects.

Both seeds are described as **non-renewable** in the 0.4.0 release. The fruits can be eaten even when the player is already full.

## ✨ How to Obtain Them

Explore the [Ultra Dimensions](ultra_dimensions.md) and search for their destination-specific souvenirs and rewards. Different destinations have different drops. The source does not justify promising a single fixed recipe or acquisition method for every item in Cobblemon Realms.

{% hint style="warning" %}
**Cobblemon Realms:** CobbleSafari 0.4.1 is included in modpack v6.3, but the default behavior described here can be altered by server settings, custom datapacks, difficulty or enabled addons. When in doubt, follow the actual in-game interface.
{% endhint %}
