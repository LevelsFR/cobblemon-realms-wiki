# 🐉 Zygarde | Cube, Cells & Reassembly

{% hint style="info" %}
<p align="center">Mega Showdown includes a <strong>Zygarde Cube</strong> and <strong>Reassembly Unit</strong> for creating and managing Zygarde forms.</p>
{% endhint %}


![Zygarde](../imgwiki/Myth_Legends/gen_6/zygarde.png)

## 🧰 Required Items

- **Zygarde Cube**: `mega_showdown:zygarde_cube`
- **Zygarde Cell**: `mega_showdown:zygarde_cell`
- **Zygarde Core**: `mega_showdown:zygarde_core`
- **Reassembly Unit**: `mega_showdown:reassembly_unit`

## 🧪 Assembly Requirements

| Assembly | Cells | Cores | Processing time |
| --- | ---: | ---: | --- |
| 10% Forme | 9 | 1 | 2 minutes |
| 50% Forme | 49 | 1 | 5 minutes |
| 50% Forme with Power Construct | 95 | 5 | 10 minutes |

{% hint style="info" %}
These are exact values from the upstream Reassembly Unit logic, not an estimate. The 95 Cell / 5 Core result has **Power Construct** and starts in 50% form. Complete Forme is associated with its battle mechanic, not a separate 100% Pokémon produced by this machine.
{% endhint %}

## 🏗️ How to Assemble

{% stepper %}
{% step %}
### 📦 Fill the Cube
Open the Zygarde Cube and add Cells and Cores.
{% endstep %}
{% step %}
### ⚙️ Start the Machine
Use the Cube on the **Reassembly Unit** to begin processing.
{% endstep %}
{% step %}
### ⏳ Finish Assembly
After processing completes, use a **Poké Ball** on the machine to receive Zygarde.
{% endstep %}
{% endstepper %}

### 🔁 Switching Existing Forms

The Cube can store or release Zygarde. When used on a Zygarde with Power Construct, its code allows switching between 10% and 50% forms. Reassembly can also recover Cells and a Core from a stored 10% or 50% Zygarde.


{% hint style="warning" %}
**Modpack note:** These mechanics are documented from Mega Showdown's upstream source. Item acquisition, recipes and enabled features may differ with the installed Cobblemon Realms version or server configuration. An upstream item existing does not prove it is obtainable in survival here.
{% endhint %}
