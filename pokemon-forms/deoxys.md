# 🧬 Deoxys | Normal, Attack, Speed & Defense

{% hint style="info" %}
<p align="center">Mega Showdown provides a Deoxys Meteorite that cycles through Deoxys's four combat forms.</p>
{% endhint %}


## 🔄 Change Form

1. Obtain the **Deoxys Meteorite**, item `mega_showdown:deoxys_meteorite`.
2. Hold and use the Meteorite, then select **Deoxys** from your party.
3. Reuse it to switch to the next form.

| Starting form | Next form |
| --- | --- |
| Normal | Attack |
| Attack | Speed |
| Speed | Defense |
| Defense | Normal |

{% hint style="info" %}
The order above follows the current upstream method. If Deoxys does not have a recognized starting form, the item does not advance it.
{% endhint %}


{% hint style="warning" %}
**Modpack note:** These mechanics are documented from Mega Showdown's upstream source. Item acquisition, recipes and enabled features may differ with the installed Cobblemon Realms version or server configuration. An upstream item existing does not prove it is obtainable in survival here.
{% endhint %}
