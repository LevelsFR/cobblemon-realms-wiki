# 🪐 Legendary Forms | Orbs, Masks & Held Items

{% hint style="info" %}
<p align="center">These Mega Showdown form changes are activated by giving a specific item to the Pokémon, unlike the click-and-select items used for Shaymin, Hoopa and Deoxys.</p>
{% endhint %}

## 🎮 Using a Held Form Item

1. Give the specific item to the matching Pokémon in its held-item slot.
2. The mod applies the corresponding transformation.
3. Removing that item triggers the reverse operation when applicable.

{% hint style="warning" %}
**Do not confuse items with similar names.** Mega Showdown registers the **Adamant Orb, Lustrous Orb and Griseous Orb** separately from the **Adamant Crystal, Lustrous Globe and Griseous Core**. The form-change handler in this guide is registered for the latter three.
{% endhint %}

Other items: [Arceus and Silvally](type-forms.md), [Therian forms](../pokemons-exclusives/therian-forms.md), [Necrozma](../pokemons-exclusives/necrozma-fusions.md).

**Modpack note:** These mechanics are documented from Mega Showdown's upstream source. Item acquisition, recipes and enabled features may differ with the installed Cobblemon Realms version or server configuration. An upstream item existing does not prove it is obtainable in survival here.
{% endhint %}
