## 🛠️ Which Interaction Should I Use?

| Mechanic | How it works |
| --- | --- |
| **Pokémon-selecting item** | Use the item in your hand and select an eligible Pokémon from your party |
| **Held item** | Give the required item to the Pokémon to activate the associated form; remove it to revert |
| **Fusion item** | Send out the partner, store it in the fusion item, then apply that item to the primary Pokémon |
| **Machine** | Use a Zygarde Cube with the Reassembly Unit |

{% hint style="info" %}
**Separate categories:** [Pokémon Exclusives](../pokemons-exclusives/baby-legends.md) covers modpack-specific species and variants, while Pokémon Cosmetics covers appearance-only differences. This section focuses on transformations with a gameplay mechanic.
{% endhint %}
