# 🎭 Other Form Changes | Rotom & Oricorio

{% hint style="info" %}
<p align="center">Not every gameplay form is Legendary. Mega Showdown also registers reusable form mechanics for ordinary Pokémon.</p>
{% endhint %}


## ⚡ Rotom

The **Rotom Catalogue** (`mega_showdown:rotom_catalogue`) lets you cycle the available forms. Mega Showdown also supplies form-specific appliances such as ovens, fans, mowers, fridges and washing machines.

The catalogue rotates through **Heat → Fan → Mow → Frost → Wash → Normal**, then repeats.

For illustrations, recipes and additional spawn information, see [Rotom's existing guide](../pokemons-exclusives/rotom-forms.md).

## 🌺 Oricorio

Use the matching Nectar to select a style:

| Nectar | Style |
| --- | --- |
| `mega_showdown:red_nectar` | Baile |
| `mega_showdown:yellow_nectar` | Pom-Pom |
| `mega_showdown:pink_nectar` | Pa'u |
| `mega_showdown:purple_nectar` | Sensu |

These are Pokémon-selecting items, not held items.

## ⚔️ In-battle Changes

Mega Showdown also defines battle-dependent form changes, including Aegislash, Castform, Cherrim, Palafin, Meloetta and others. These should **not** be treated as permanently selectable out-of-battle forms. Their triggers are not fully documented here.


{% hint style="warning" %}
**Modpack note:** These mechanics are documented from Mega Showdown's upstream source. Item acquisition, recipes and enabled features may differ with the installed Cobblemon Realms version or server configuration. An upstream item existing does not prove it is obtainable in survival here.
{% endhint %}
