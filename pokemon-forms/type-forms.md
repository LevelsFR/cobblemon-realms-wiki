# 🌈 Type-Based Forms | Arceus, Silvally & Genesect

{% hint style="info" %}
<p align="center">Held items in Mega Showdown determine the elemental aspect or form of several Pokémon.</p>
{% endhint %}


## ✨ Arceus Plates

Arceus uses an appropriate **Plate** as its held item. The upstream registry includes Fire, Water, Electric, Grass, Ice, Fighting, Poison, Ground, Flying, Psychic, Bug, Rock, Ghost, Dragon, Dark, Steel and Fairy Plates.

Examples: `mega_showdown:flame_plate` (Fire), `mega_showdown:splash_plate` (Water), `mega_showdown:pixie_plate` (Fairy).

## 🧬 Silvally Memories

Silvally uses **Memory** items to change the RKS-based type/form. Examples: `mega_showdown:fire_memory`, `mega_showdown:water_memory`, `mega_showdown:dark_memory`.

## ⚙️ Genesect Drives

| Item | Type association |
| --- | --- |
| `mega_showdown:burn_drive` | Fire |
| `mega_showdown:chill_drive` | Ice |
| `mega_showdown:douse_drive` | Water |
| `mega_showdown:shock_drive` | Electric |

The Genesect registration modifies its Drive aspect. This does not mean Genesect becomes a new elemental species.

## 🔄 Usage

Give the matching Plate, Memory or Drive to its respective Pokémon. Change or remove the held item to apply or revert its effect.


{% hint style="warning" %}
**Modpack note:** These mechanics are documented from Mega Showdown's upstream source. Item acquisition, recipes and enabled features may differ with the installed Cobblemon Realms version or server configuration. An upstream item existing does not prove it is obtainable in survival here.
{% endhint %}
