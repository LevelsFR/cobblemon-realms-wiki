# ⚠️ Preparing for the Planned Create Removal

{% hint style="warning" %}
**Planned for Cobblemon Realms 6.4, not a current v6.3 change.** Create is still part of the published **Full 6.3** edition. The exact 6.4 release details and distribution of the optional compatibility archive must be confirmed when the update is published.
{% endhint %}

## What needs attention before upgrading?

Create machines, moving contraptions and connected storage may depend on blocks, items and data provided by Create or its addons. Removing those mods can make affected content unavailable, and reopening or resaving a world without the relevant mods may cause irreversible changes.

## Recommended precautions

1. **Make a complete backup** of your world and player data. Keep an untouched copy outside the game instance.
2. **Check every Create-based storage system**, including vaults, conveyors, depots, processing lines, contraptions and any linked inventories.
3. **Move valuable items into standard Minecraft storage** where possible. Check that those containers do not depend on Create or another planned-to-be-removed addon.
4. **Document your machines** with screenshots and, where appropriate, compatible schematic exports. A screenshot is not a world backup.
5. **Test the upgrade on a copy of the world** with the exact future modpack and server-pack versions. Do not run this test on the only remaining save.
6. **Wait for the confirmed update instructions** before removing mods from an existing world.

## Optional compatibility archive

The project has announced an intention to provide a **separate Create mod archive on the official Discord**, allowing players to continue using compatible mods manually where feasible. **Availability, contents and compatibility are not yet confirmed here.** Do not install an unofficial mirror or assume old addons remain compatible.

[Official Discord](https://discord.gg/kb8NSTF45n) · [Current Version History](version-history.md) · [Installation Guide](installation.md)

Never upgrade an important world without a tested backup, especially when a release removes world-generation, block, item or storage mods.
{% endhint %}
