## 🌍 Guide Freeroam - Jouer sans Level Cap

{% hint style="info" %}
Le **Mode Freeroam** vous permet de mettre temporairement votre progression scénarisée en pause afin d’explorer librement le monde, entraîner vos Pokémon jusqu’au **niveau 100** et profiter du modpack sans restriction de niveau.
{% endhint %}

### ℹ️ Qu’est-ce que le Freeroam ?

Le **Mode Freeroam** permet de désactiver temporairement les restrictions liées à votre série de dresseurs actuelle. Votre progression principale reste intacte et peut être reprise à tout moment.

| | Fonction |
| --- | --- |
| ✅ | Plus aucune restriction de niveau |
| ✅ | Pokémon pouvant atteindre le **niveau 100** |
| ✅ | Exploration libre de toutes les régions |
| ✅ | Capture et entraînement sans contraintes |
| ✅ | Retour à votre série principale à tout moment |

{% hint style="warning" %}
⚠️ Le Freeroam **ne supprime pas votre progression**. Votre série principale est simplement mise en pause pendant que vous jouez librement.
{% endhint %}

### 📖 Activer le Freeroam

Suivez ces quatre étapes depuis le menu des quêtes :

#### 🧭 1. Ouvrir les Quêtes

Ouvrez votre inventaire puis cliquez sur le petit livre `Quests`, situé en haut à gauche de votre écran.

#### 📂 2. Afficher les catégories

Passez votre curseur sur le côté gauche de l’écran afin de faire apparaître la liste des catégories disponibles.

#### 📘 3. Ouvrir le Guide de bienvenue

Dans la liste des catégories, sélectionnez `Guide de bienvenue`.

#### 🪙 4. Activer le Freeroam

Tout en bas du menu, vous trouverez un `Realms Coin`. Cliquez dessus pour entrer en mode `Freeroam`.

### 🔄 Reprendre votre progression

Vous pouvez revenir à votre aventure principale **à n’importe quel moment**.

| Méthode | Action |
| --- | --- |
| 📌 **Menu FTB Quests** | Utilisez le bouton dédié à votre région. |
| 🧑‍🏫 **Association des Dresseurs** | Faites apparaître un PNJ de l’`Association des Dresseurs`, puis sélectionnez la série que vous souhaitez reprendre. |

{% hint style="success" %}
✅ Votre progression restera exactement au même endroit.
{% endhint %}

### ✨ Pourquoi utiliser le Freeroam ?

Le Freeroam est particulièrement intéressant si vous souhaitez :

- 🌍 **Explorer librement** toutes les régions
- ⚔️ **Entraîner vos équipes** sans limite de niveau
- 📚 **Compléter votre Pokédex**
- 🎣 **Chasser des Pokémon rares**
- 🧪 **Tester différentes équipes**
- 🏕️ **Jouer de manière plus sandbox et détendue**

{% hint style="info" %}
💡 Le Freeroam est une **alternative optionnelle** au système de progression classique. Vous pouvez alterner librement entre aventure scénarisée et exploration libre selon votre façon de jouer.
{% endhint %}

## 📊 Système de niveau maximum (Level Cap)

Chaque joueur possède un **niveau maximum personnel**, commençant à **25** dans ce modpack (par défaut, il est plus bas dans le mod original).

### ⚙️ Que fait le Level Cap ?

Le niveau maximum influence directement vos Pokémon et les dresseurs que vous pouvez affronter :

| Effet | Fonctionnement |
| --- | --- |
| 🛑 **Expérience** | Les Pokémon **ayant atteint ou dépassé** votre niveau maximum **ne peuvent plus gagner d’expérience**. |
| 🚫 **Combats** | Les dresseurs **refuseront de se battre** si un Pokémon de votre équipe dépasse ce niveau. |
| 🎯 **Niveau des dresseurs** | La **puissance des dresseurs proches** s’adapte à votre équipe, mais **ne dépasse jamais votre niveau maximum**. |

### 🧭 Comment augmenter votre cap ?

Pour augmenter votre niveau maximum, vous devez progresser dans le système de **Dresseurs Clés** :

1. 🏆 Vainquez les **Dresseurs Clés** dans l’ordre précis défini par le système de progression.
2. 🪪 Consultez votre **Carte de Dresseur** pour connaître votre prochain Dresseur Clé et obtenir des indices sur l’endroit où le trouver.
3. 📖 Consultez l’onglet **Avancements** pour découvrir des étapes supplémentaires et obtenir de nouveaux indices.

## 🔍 Dresseurs Clés & système de suivi

Les **Dresseurs Clés** constituent les principaux points de progression. Les vaincre augmente votre niveau maximum et débloque progressivement des défis plus difficiles.

### 🧭 Fonctionnement du suivi

Au début du jeu, lorsque vous obtenez une **Carte de Dresseur** mais que **vous n’avez aucune série de dresseurs active**, une **flèche holographique** apparaît.

→ Cette flèche **pointe toujours vers le PNJ de l’Association des Dresseurs**, afin de vous permettre de commencer votre première série.

Une fois une série choisie :

- la flèche disparaît ;
- il **n’y a pas de flèche vers les Dresseurs Clés** eux-mêmes ;
- vous devez utiliser les informations de votre **Carte de Dresseur** pour les localiser.

Les informations disponibles peuvent notamment indiquer :

- 🗺️ les **noms des biomes** ;
- ✨ les **conditions spéciales** ;
- 🎒 les **objets requis** pour les invoquer, lorsque cela est nécessaire.

### 🌍 Trouver les Dresseurs Clés dans Cobblemon Realms

Dans **Cobblemon Realms**, le système de quêtes fournit plusieurs outils supplémentaires pour faciliter leur recherche.

Chaque catégorie de quêtes répertorie **tous les dresseurs d’une série**. Vous pouvez également **échanger des Realms Coins** pour faire apparaître instantanément le dresseur que vous devez affronter.

{% hint style="info" %}
💡 Les dresseurs peuvent être générés <strong>à l’infini</strong> de cette manière.
{% endhint %}

Une fois vaincu, un dresseur ne peut cependant pas être réaffronté immédiatement.

> ⏱️ **Temps de recharge :** un dresseur vaincu doit attendre **un jour Minecraft**, soit environ **20 minutes IRL**, avant de pouvoir être affronté à nouveau.

Les quêtes disposent également d’un **bouton Info**, qui permet d’accéder à plusieurs outils :

| Fonction | Description |
| --- | --- |
| 🧭 **Activer une série à distance** | Permet d’activer une série sans devoir retrouver physiquement l’Association des Dresseurs. |
| 📈 **Graphique de progression** | Affiche l’ordre des dresseurs ainsi que leur **niveau moyen**. |
| 🏆 **Avancements** | Renvoie vers les **Avancements** correspondants afin de suivre directement votre progression dans Minecraft. |

{% hint style="warning" %}
⚠️ <strong>Une seule série peut être active à la fois.</strong> Activer une autre série réinitialise la progression de la série actuelle, sauf si celle-ci est déjà terminée.
{% endhint %}

## 🏆 Champions d’Arène & Dresseurs Majeurs

La progression ne se limite pas à l’augmentation du **Level Cap**. En avançant dans les différentes séries, vous débloquez également l’accès aux **Champions d’Arène**, **Rivaux**, **Conseil 4**, **équipes de vilains** et autres défis majeurs.

### 🔓 Conditions de déblocage

| | Condition |
| --- | --- |
| 🥇 | Vaincre les **Dresseurs Clés** requis d’une série pour débloquer ses adversaires de haut niveau. |
| 💠 | Certains dresseurs nécessitent des **objets spéciaux** (ex. _Pierre Dure_) pour être invoqués. |
| 🧱 | Utiliser un **Générateur de Dresseurs**, trouvé dans les villages ou les arènes, puis faire un clic droit avec l’objet requis pour invoquer le dresseur après un court délai. |
| 🧩 | Les contenus avancés comme les **Ligues**, le **Conseil 4** ou les **chefs d’équipes** peuvent nécessiter plusieurs séries terminées. |

{% hint style="info" %}
💡 <strong>Votre progression est non linéaire.</strong> Vous pouvez suivre un chemin unique ou progresser dans plusieurs séries en parallèle afin de débloquer différents contenus.
{% endhint %}

## 🤝 Association des Dresseurs

L’**Association des Dresseurs** est un PNJ spécial qui vous permet de commencer une nouvelle série et d’accéder à son parcours de progression.

### 🧑‍🏫 Quand apparaît-elle ?

L’Association des Dresseurs apparaît près d’un joueur qui :

- possède une **Trainer Card**, en main ou dans son inventaire ;
- **n’a aucune série de dresseurs active**.

Lorsqu’elle se trouve à proximité, votre **Carte de Dresseur** :

- ✨ **brille** ;
- 🧭 affiche une **flèche** indiquant la direction du PNJ.

Une fois auprès de l’Association des Dresseurs, celle-ci propose un **menu de séries**. Chaque série possède son propre thème, son parcours de progression et sa difficulté.

## 📈 Graphique de progression

Le système de **Radical Trainers** permet de visualiser votre progression complète à travers les différentes séries de dresseurs.

Utilisez la commande : `/rctmod player get progress <pseudo> graph include_defeated include_optionals`

Le graphique permet notamment de voir :

| Indicateur | Signification                            |
| ---------- | ---------------------------------------- |
| ✔️         | Séries terminées                         |
| 🟡         | Chemins optionnels                       |
| 🔒         | Contenu encore verrouillé                |
| 🔁         | Dépendances entre les différentes séries |

## 🎯 Avancements

Les **Avancements** permettent de suivre votre progression directement en jeu et peuvent également servir de système d’indices.

Chaque série possède ses **propres avancements**, dont certains peuvent être cachés. Selon votre progression, ils peuvent vous aider à identifier les prochaines étapes ou à débloquer de nouveaux contenus.

Les récompenses peuvent notamment inclure :

* 🎁 Des objets
* 🪙 Des Realms Coins
* 🔓 Des conditions permettant de débloquer de nouveaux contenus
