# 🦜 Effets des Pokémon sur l'épaule

## 🎒 Effets des Pokémon sur l'épaule (v5.0)

{% hint style="warning" %}
<p align="center">
Les informations de cette page ne sont plus à jour. Comme les fichiers/dossiers associés ne sont plus présents dans le datapack, ces fonctionnalités sont actuellement <strong>en attente</strong> jusqu'à leur réintroduction dans le modpack.
</p>
{% endhint %}

{% hint style="info" %}
<p align="center">
Les <strong>montures d'épaule</strong> sont des Pokémon qui peuvent être placés sur vos épaules afin de vous accorder des <strong>bonus passifs uniques</strong>. Utilisez la commande <code>/shoulder</code> pour afficher la liste complète des montures d'épaule disponibles et de leurs effets. Pour équiper une monture d'épaule, libérez votre Pokémon, maintenez <code>Shift + Clic droit</code> sur celui-ci, puis sélectionnez <strong>Épaule</strong>. Certains effets nécessitent d'équiper deux montures d'épaule simultanément pour s'activer.
</p>
{% endhint %}

<p align="center">
ℹ️ <em>Les effets restent actifs tant que le Pokémon reste sur votre épaule.</em>
</p>

## ⚙️ Informations

- Plusieurs effets peuvent être actifs simultanément.
- L'amplificateur correspond au niveau de l'effet :
  - Niveau I = `0`
  - Niveau II = `1`
  - Niveau III = `2`
- Certains effets ont été ajustés à des fins d'équilibrage du modpack.
