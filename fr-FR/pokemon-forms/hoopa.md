# 🌀 Hoopa | Enchaîné et Déchaîné

{% hint style="info" %}
<p align="center">Le <strong>Vase Scellé</strong> de Mega Showdown permet d'alterner entre les formes Enchaînée et Déchaînée de Hoopa.</p>
{% endhint %}


## 🔄 Comment faire ?

1. Procurez-vous le **Vase Scellé**, identifiant `mega_showdown:prison_bottle`.
2. Utilisez le vase puis sélectionnez **Hoopa** dans votre équipe.
3. Répétez l'opération pour revenir à la forme **Enchaînée**.

| Forme actuelle | Interaction |
| --- | --- |
| Enchaînée | Vase Scellé → Déchaînée |
| Déchaînée | Vase Scellé → Enchaînée |

{% hint style="info" %}
Il s'agit de la mécanique de Mega Showdown, distincte des [portails de Hoopa de CobbleSafari](../mods-guides/CobbleSafari/hoopa_portals.md).
{% endhint %}


{% hint style="warning" %}
**Note pour le modpack :** ces mécaniques proviennent du code source de Mega Showdown. L'obtention des objets, les recettes et les fonctionnalités actives peuvent varier selon la version installée dans Cobblemon Realms et la configuration du serveur. La présence d'un objet dans le code ne garantit pas son obtention en survie.
{% endhint %}
