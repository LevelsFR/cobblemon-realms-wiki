# 🪐 Formes légendaires | Orbes, masques et objets tenus

{% hint style="info" %}
<p align="center">Ces transformations sont activées en confiant au Pokémon un <strong>objet à tenir</strong>, contrairement à Shaymin, Hoopa et Deoxys qui utilisent une sélection dans l'équipe.</p>
{% endhint %}


## 🧾 Référence des objets tenus

| Pokémon | Objet | Forme / Effet |
| --- | --- | --- |
| Groudon | `mega_showdown:red_orb` | Primo-Résurgence |
| Kyogre | `mega_showdown:blue_orb` | Primo-Résurgence |
| Dialga | `mega_showdown:adamant_crystal` | Forme Originelle |
| Palkia | `mega_showdown:lustrous_globe` | Forme Originelle |
| Giratina | `mega_showdown:griseous_core` | Forme Originelle |
| Zacian | `mega_showdown:rusted_sword` | Épée Suprême |
| Zamazenta | `mega_showdown:rusted_shield` | Bouclier Suprême |
| Ogerpon | `mega_showdown:cornerstone_mask` | Masque de la Pierre, type Téracristal Roche |
| Ogerpon | `mega_showdown:wellspring_mask` | Masque du Puits, type Téracristal Eau |
| Ogerpon | `mega_showdown:hearthflame_mask` | Masque du Fourneau, type Téracristal Feu |

## 🎮 Utilisation

1. Confiez l'objet approprié au Pokémon en tant qu'**objet tenu**.
2. Le mod applique la forme correspondante.
3. Retirez l'objet pour déclencher le retour à la forme précédente lorsque cette mécanique le prévoit.

{% hint style="warning" %}
**Attention aux objets presque homonymes.** Mega Showdown enregistre séparément les **Orbes Adamant, Perlé et Platiné** et les **Cristal Adamant, Globe Perlé et Noyau Platiné**. Le système de changement de forme décrit ici utilise ce second groupe.
{% endhint %}

À consulter aussi : [Arceus et Silvallié](type-forms.md), [Formes Totémiques](../pokemons-exclusives/therian-forms.md), [Necrozma](../pokemons-exclusives/necrozma-fusions.md).

L'obtention des objets, les recettes et les fonctionnalités actives peuvent varier selon la version installée dans Cobblemon Realms et la configuration du serveur. La présence d'un objet dans le code ne garantit pas son obtention en survie.
{% endhint %}
