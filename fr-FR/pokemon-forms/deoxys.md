# 🧬 Deoxys | Formes Normale, Attaque, Vitesse et Défense

{% hint style="info" %}
<p align="center">Mega Showdown propose une <strong>Météorite de Deoxys</strong> permettant de parcourir ses quatre formes.</p>
{% endhint %}


## 🔄 Changer de forme

1. Obtenez la **Météorite de Deoxys**, identifiant `mega_showdown:deoxys_meteorite`.
2. Tenez-la en main, utilisez-la puis sélectionnez **Deoxys** dans votre équipe.
3. Répétez l'opération pour passer à la forme suivante.

| Forme actuelle | Forme suivante |
| --- | --- |
| Normale | Attaque |
| Attaque | Vitesse |
| Vitesse | Défense |
| Défense | Normale |

{% hint style="info" %}
Cet ordre vient de la méthode actuelle du mod. Si Deoxys ne possède aucune forme de départ reconnue, l'objet ne fait pas avancer la séquence.
{% endhint %}


{% hint style="warning" %}
**Note pour le modpack :** ces mécaniques proviennent du code source de Mega Showdown. {% endhint %}
