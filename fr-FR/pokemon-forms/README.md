## 🛠️ Quelle interaction utiliser ?

| Mécanique | Fonctionnement |
| --- | --- |
| **Objet avec sélection** | Utilisez l'objet en main puis sélectionnez le Pokémon concerné dans l'équipe |
| **Objet tenu** | Confiez l'objet au Pokémon pour appliquer la forme correspondante, retirez-le pour revenir à la forme précédente |
| **Objet de fusion** | Sortez le partenaire, stockez-le dans l'objet puis utilisez celui-ci sur le Pokémon principal |
| **Machine** | Utilisez le Cube de Zygarde sur l'unité de réassemblage |

{% hint style="info" %}
**Rubriques distinctes :** [Pokémon exclusifs](../pokemons-exclusives/baby-legends.md) présente les espèces et variantes propres au modpack. La rubrique Cosmétiques Pokémon est réservée aux apparences. Vous trouverez ici les transformations ayant une mécanique de jeu.
{% endhint %}
