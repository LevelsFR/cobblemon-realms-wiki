# 🌈 Formes liées au type | Arceus, Silvallié et Genesect

{% hint style="info" %}
<p align="center">Dans Mega Showdown, certains objets tenus déterminent le type ou l'aspect du Pokémon.</p>
{% endhint %}


## ✨ Plaques d'Arceus

Arceus utilise une **Plaque** adaptée en objet tenu. Le registre comprend les plaques Feu, Eau, Électrik, Plante, Glace, Combat, Poison, Sol, Vol, Psy, Insecte, Roche, Spectre, Dragon, Ténèbres, Acier et Fée.

Exemples : `mega_showdown:flame_plate` (Feu), `mega_showdown:splash_plate` (Eau), `mega_showdown:pixie_plate` (Fée).

## 🧬 ROM de Silvallié

Silvallié utilise des objets de type **Memory** pour changer son type et sa forme RKS. Exemples : `mega_showdown:fire_memory`, `mega_showdown:water_memory`, `mega_showdown:dark_memory`.

## ⚙️ Modules de Genesect

| Objet | Type associé |
| --- | --- |
| `mega_showdown:burn_drive` | Feu |
| `mega_showdown:chill_drive` | Glace |
| `mega_showdown:douse_drive` | Eau |
| `mega_showdown:shock_drive` | Électrik |

Pour Genesect, l'objet modifie l'aspect lié au Module, sans transformer Genesect en une autre espèce élémentaire.

## 🔄 Utilisation

Confiez la Plaque, la ROM ou le Module au Pokémon correspondant. Remplacez ou retirez cet objet tenu pour appliquer ou annuler la modification.
