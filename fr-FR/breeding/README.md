# 🥚 Élevage Pokémon | Cobbreeding

{% hint style="info" %}
<p align="center">
<strong>Donnez naissance à une nouvelle génération de Pokémon.</strong> Cobbreeding ajoute un système d'élevage au <strong>bloc de pâturage (Pasture Block)</strong> de Cobblemon. Les Pokémon compatibles peuvent produire des œufs tout en se promenant autour de votre base. Ce guide présente le système pour les joueurs de <strong>Cobblemon Realms</strong>.
</p>
{% endhint %}

## 🌱 Qu'est-ce que Cobbreeding ?

Développé par **Ludichat et Fuzuki**, Cobbreeding enrichit le bloc de pâturage existant avec un bouton d'activation de l'élevage et une zone de collecte des œufs. Son fonctionnement s'inspire du système de pique-nique de Pokémon Écarlate et Violet.

L'élevage permet notamment de :

- 🥚 Obtenir des œufs de Pokémon compatibles, sans pension séparée.
- 🧬 Rechercher de bons IV, des Natures, des talents, des capacités et certaines formes héritées.
- ✨ Profiter de méthodes de recherche de Pokémon chromatiques configurables.
- 🏡 Aménager un espace d'élevage sécurisé dans votre base.

{% hint style="warning" %}
<strong>Les paramètres peuvent varier.</strong> La vitesse de production des œufs, les chances de chromatique, les limites et l'automatisation dépendent de la configuration du monde ou du serveur. Les valeurs du guide de l'auteur ne sont pas nécessairement celles du serveur public Cobblemon Realms.
{% endhint %}

## 🚀 Démarrer rapidement

{% stepper %}
{% step %}
### 🏡 Placez un bloc de pâturage

Prévoyez assez d'espace **derrière le bloc** pour que les Pokémon puissent apparaître et se déplacer sans risque.
{% endstep %}
{% step %}
### 🔘 Activez l'élevage

Ouvrez le bloc et utilisez le **bouton d'élevage** dans la partie supérieure droite de l'interface. L'élevage est désactivé par défaut.
{% endstep %}
{% step %}
### 💞 Choisissez des Pokémon compatibles

Sélectionnez vos Pokémon depuis votre stockage. En règle générale, ils doivent être de sexes opposés et partager un groupe d'œufs. **Métamorph** possède des règles particulières.
{% endstep %}
{% step %}
### 🥚 Récupérez et faites éclore les œufs

Après un certain délai, récupérez les œufs **sous le bloc de pâturage**. Gardez-les dans **l'inventaire de votre personnage** pour faire progresser leur éclosion.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Pour aller plus loin :** suivez les guides ci-dessous, de l'installation de votre premier pâturage aux mécaniques d'héritage et au dépannage.
{% endhint %}
