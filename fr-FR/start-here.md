# 🚀 Bien démarrer sur Cobblemon Realms

{% hint style="info" %}
**Bienvenue dans Cobblemon Realms !** Cette checklist correspond à l'expérience officielle **v6.3**. Avancez à votre rythme. La progression est enregistrée **uniquement dans ce navigateur**, jamais sur votre compte Minecraft ni sur le serveur.
{% endhint %}

## 🎮 Choisir votre aventure

L'édition **Full** conserve une expérience survie et construction plus complète, avec Create en v6.3. **Lite** se concentre davantage sur l'aventure Pokémon avec moins de systèmes secondaires lourds. Chaque édition a ses propres téléchargements et Server Packs.

- [Télécharger et installer Cobblemon Realms](installation.md)
- [Comparer les versions officielles et les Server Packs](version-history.md)
- [Optimiser les performances en solo](settings/optimize-solo-performance.md)
