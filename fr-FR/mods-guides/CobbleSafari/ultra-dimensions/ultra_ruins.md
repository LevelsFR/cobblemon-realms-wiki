# 🌀 Ultra Ruins | Ultra Space

{% hint style="info" %}
<p align="center">Cette fiche présente les <strong>pools de rencontres du mod officiel</strong> pour cette Ultra-Dimension. Les valeurs dépendent du rang de votre Ultra-Brèche et peuvent être modifiées par les réglages du serveur.</p>
{% endhint %}

## 🗺️ Informations sur la destination

| Propriété | Valeur |
| --- | --- |
| Identifiant de destination | `cobblesafari:ultra_ruins` |
| Type ID | `7` |
| Teinte du portail | `#d7d7d7` |
| Extension | CobbleSafari 0.4.x |

---

## 🐾 Pool ordinaire

Le fichier officiel propose ces huit Pokémon pour le pool ordinaire :

- **Tyranitar**
- **Galarian Weezing**
- **Garbodor**
- **Alolan Muk**
- **Conkeldurr**
- **Golurk**
- **Chandelure**
- **Obstagoon**

---

## ⭐ Pool spécial pondéré

| Pokémon | Poids |
| --- | ---: |
| **Guzzlord** | 10 |
| **Stakataka** | 30 |
| **Blacephalon** | 30 |
| **Poipole** | 30 |

{% hint style="warning" %}
**Attention :** ces poids sont relatifs à la sélection du **pool spécial**, pas aux chances globales de trouver chaque Pokémon. Le système Ultra Warp Ride doit d'abord sélectionner le niveau de récompense concerné. La présence des espèces dépend également des addons activés.
{% endhint %}

---

## 🎁 Butin et souvenirs associés

Le mod contient une table de butin associée au Pokémon spécial de cette destination. Elle référence notamment `cobblesafari:gluton_armor_helmet`.

La présence de l'objet dans cette table **ne garantit pas sa récupération** pendant chaque visite. D'autres objets comme des éléments d'armure Ultra Recon peuvent également être inclus dans les tables officielles.

---

## 🧭 Comment accéder à cette destination

1. Entrez dans [Ultra Mégalopole](../ultra_megalopolis.md).
2. Lancez [Ultra Warp Ride](../ultra_warp_ride.md), récupérez des bonus et évitez les obstacles.
3. Choisissez une brèche menant à cette destination et découvrez votre rencontre.
