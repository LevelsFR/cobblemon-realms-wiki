# ✨ Lost Items et Poké Balls porte-bonheur

{% hint style="info" %}
<p align="center">Trouvez des objets dans les donjons et découvrez leurs nouveaux visuels, récompenses depuis CobbleSafari 0.4.</p>
{% endhint %}


## 🎁 À quoi servent-ils ?

Les **Lost Items** sont des objets à récupérer au cours d'une exploration. Ils peuvent prendre la forme de Poké Balls, de trouvailles enterrées ou d'étincelles au sol. Leur collecte peut compter pour les objectifs dimensionnels.

## 🎨 Apparences disponibles

| Style | Description |
| --- | --- |
| **Rubble** | Apparence d'origine dans les décombres |
| **Classic** | Poké Ball traditionnelle |
| **Buried** | Objet partiellement enterré |
| **Floating** | Poké Ball en lévitation et en rotation |
| **Sparkles** | Étincelles au sol inspirées de Pokémon Légendes Z-A, récupérables en marchant dessus |

Le modèle de Poké Ball peut utiliser différents modèles 3D de Cobblemon.

## 🛡️ Comment les récupérer ?

Interagissez avec les objets trouvés dans les donjons pour obtenir leurs récompenses. Les Lost Items, Lost Notes et Poké Balls porte-bonheur **ne peuvent pas être cassés en survie**.

## 🧭 Où les rencontrer ?

- [Hyperspace Lumiose](hyperspace_lumiose.md), notamment les objets flottants et scintillants ;
- [Tour Carillon](bell_tower.md), avec des correctifs de butin en 0.4.1 ;
- [Objectifs dimensionnels](dimensional_objectives.md), dont certaines tâches consistent à les ramasser.
