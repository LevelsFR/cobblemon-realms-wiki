# 🎁 Objets et équipements d'Ultra Space

{% hint style="info" %}
<p align="center">Les Ultra-Dimensions offrent de nouveaux équipements, projectiles, accessoires et plantes introduits par CobbleSafari 0.4.0.</p>
{% endhint %}


## 🛡️ Armures et protection

| Objet | Fonction |
| --- | --- |
| **Armure Ultra Recon** | Effet Élytres avec l'ensemble complet si activé, protection supplémentaire en Ultra Warp Ride |
| **Armure Glutton** | Confère des bonus liés à la satiété lors des repas |
| **Stacked Shield** | Bloque les dégâts et procure un bonus, puis nécessite un rechargement |
| **Nihilhat** | Procure Conduit Power sous l'eau ou sous la pluie avec une barre de faim non vide, mais applique Faim III et peut provoquer des nausées |

## 🎯 Outils et projectiles

| Objet | Fonction |
| --- | --- |
| **Needle Dart** | Projectile très rapide, non affecté par la gravité |
| **Harlequin Bomb** | Produit une explosion de feu d'artifice aléatoire |
| **Static Heap** | Peut appeler la foudre lorsqu'il atterrit sans obstruction au-dessus |
| **Stellar Canon** | Utilise de la poudre à canon pour projeter des signaux fumigènes |
| **Origami Carrier** | Projette des avions en papier grâce au papier |

## 🌱 Plantes particulières

- **Beefy Seed** : fait pousser une Beefy Plant, dont les fruits procurent Force, Résistance et Célérité.
- **Beauty Seed** : fait pousser une Beauty Plant, dont les fruits procurent Invisibilité, Vitesse et Saut amélioré.

Les deux graines sont décrites comme **non renouvelables** dans les notes 0.4.0. Leurs fruits peuvent être consommés même avec la barre de faim pleine.

## ✨ Où les obtenir ?

Explorez [les Ultra-Dimensions](ultra_dimensions.md) pour découvrir leurs souvenirs et récompenses. Chaque destination possède ses propres objets. Ce guide ne prétend pas connaître une recette unique pour tous les objets sur le serveur Cobblemon Realms.

{% hint style="warning" %}
**Cobblemon Realms :** ces informations proviennent de CobbleSafari **0.4.0/0.4.1**, intégré au modpack **6.3**. Les conditions peuvent dépendre de la configuration du serveur, des addons et des datapacks. Référez-vous à l'interface du jeu lorsqu'elle indique des règles différentes.
{% endhint %}

## 🧾 Identifiants techniques confirmés

Les identifiants ci-dessous apparaissent dans les tables de butin officielles de la 0.4. Ils peuvent aider à retrouver les objets dans JEI ou à contrôler un datapack.

| Objet / Ensemble | Identifiant |
| --- | --- |
| Needle Dart | `cobblesafari:poipole_arrow` |
| Harlequin Bomb | `cobblesafari:blacephalon_bomb` |
| Static Heap | `cobblesafari:xurkitree_bomb` |
| Stellar Canon | `cobblesafari:celesteela_canon` |
| Origami Carrier | `cobblesafari:kartana_canon` |
| Stacked Shield | `cobblesafari:stakataka_shield` |
| Nihilhat | `cobblesafari:nihilego_hat` |
| Graines Beefy | `cobblesafari:buzzwole_seeds` |
| Graines Beauty | `cobblesafari:pheromosa_seeds` |
| Armure Ultra Recon | `cobblesafari:recon_armor_helmet` etc. |
| Armure Glutton | `cobblesafari:gluton_armor_helmet` etc. |

{% hint style="info" %}
Un identifiant est plus fiable qu'une traduction du nom de l'objet. Sa présence dans une table de butin **ne suffit pas à garantir son obtention** avec les paramètres du serveur.
{% endhint %}

[Tables de butin officielles Ultra Space](https://github.com/maxigregrze/CobbleSafari/tree/main/common/src/main/resources/data/cobblesafari/loot_table/ultraspace).
