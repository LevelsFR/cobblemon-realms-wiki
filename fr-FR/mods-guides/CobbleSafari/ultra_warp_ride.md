# 🪽 Ultra Warp Ride | Voyage à travers les brèches

{% hint style="info" %}
<p align="center">Pilotez dans un tunnel dimensionnel pour atteindre de nouveaux mondes. Votre performance influence les possibilités de récompense du Pokémon rencontré à l'arrivée.</p>
{% endhint %}


## 🚀 Déroulement du vol

{% stepper %}
{% step %}
### 1. Entrez dans Ultra Mégalopole
Rejoignez [le donjon Mégalopole](ultra_megalopolis.md) et trouvez son appareil de voyage.
{% endstep %}
{% step %}
### 2. Démarrez la traversée
Le minijeu propose un déplacement inspiré des Élytres. Utilisez les commandes de mouvement indiquées en jeu.
{% endstep %}
{% step %}
### 3. Gérez l'énergie et la distance
Récupérez les éléments positifs et évitez les obstacles négatifs. Aller plus loin peut augmenter la qualité des rencontres.
{% endstep %}
{% step %}
### 4. Traversez une Ultra-Brèche
Choisissez un portail disponible. Son apparence est associée à une destination et à un rang. Vous accédez ensuite à une Ultra-Dimension.
{% endstep %}
{% endstepper %}

## 🎁 Bonus possibles

Le modèle de difficulté officiel utilise des paliers de distance et **quatre rangs de portail**. Le résultat peut améliorer :

- Le nombre d'IV parfaits et le niveau du Pokémon ;
- Les chances de Pokémon chromatique ou Alpha ;
- Les chances de talent caché ;
- L'obtention de capacités Œuf ou de CT supplémentaires ;
- La sélection d'une rencontre rare, notamment une Ultra-Chimère.

{% hint style="warning" %}
Il s'agit de **probabilités**, et non de garanties. Un long vol ne garantit pas une Ultra-Chimère ou un Pokémon chromatique.
{% endhint %}

## 📊 Distance et difficultés

Les vols les plus longs donnent accès à des portails plus intéressants, avec des paliers à **300, 600, 1 000 et 1 500 années-lumière**. Dans le mod d'origine, les bonus d'énergie positifs cessent d'apparaître après environ **5 100 années-lumière**.

L'ensemble d'armure **Ultra Recon** peut conférer une fonction Élytres et augmenter la protection pendant le vol, si cette option est activée.
