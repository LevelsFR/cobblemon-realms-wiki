# 🍩 Donuts d'Hyperspace | Saveurs et bonus

{% hint style="info" %}
<p align="center">Les ingrédients récoltés dans Hyperspace Lumiose servent à fabriquer des <strong>donuts</strong> dans un Cooking Pot, afin d'obtenir des pouvoirs spéciaux.</p>
{% endhint %}


## 🧑‍🍳 Premiers pas

1. Explorez [Hyperspace Lumiose](hyperspace_lumiose.md) et ramassez les ingrédients disponibles.
2. Trouvez un **Cooking Pot** et ouvrez son interface.
3. Choisissez les ingrédients et préparez votre donut.
4. Examinez son infobulle pour consulter la **saveur, le palier et les effets**.

{% hint style="info" %}
Le code définit plusieurs pouvoirs et niveaux de bonus. Le résultat final dépend de la génération et des ingrédients. Aucune recette exacte ou quantité d'ingrédients n'est inventée dans ce guide.
{% endhint %}

## 🌶️ Les six familles de saveurs

| Saveur | Statistique associée |
| --- | --- |
| Épicé (Spicy) | Attaque |
| Sec (Dry) | Attaque Spéciale |
| Sucré (Sweet) | Défense |
| Acide (Sour) | Défense Spéciale |
| Amer (Bitter) | Vitesse |
| Mélangé (Mixed) | PV |

## ✨ Familles de pouvoirs

| Catégorie | Exemples présents dans le code |
| --- | --- |
| Recherche et capture | Rencontre, Capture, Chromatique, Alpha, Talent caché |
| Particularités Pokémon | Taille géante, Petite taille, Atypique, Amitié |
| Combat | Attaque, Défense, Attaque Spé., Défense Spé., Vitesse, Capacités, Résistance |
| Exploration | Chance, Récupération, Butin, Objets |

La puissance du bonus dépend notamment de son niveau et de son type. Un donut n'offre **pas automatiquement** tous ces effets.
