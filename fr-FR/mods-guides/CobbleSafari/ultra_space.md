# 🌌 Ultra Space | Guide d'exploration

{% hint style="info" %}
<p align="center">Traversez de nouvelles dimensions avec <strong>Ultra Mégalopole</strong>, <strong>Ultra Warp Ride</strong> et <strong>sept Ultra-Dimensions</strong>, introduits par CobbleSafari 0.4.</p>
{% endhint %}


## 🧭 Par où commencer ?

**Ultra Mégalopole** est un donjon servant de point de départ au voyage Ultra Warp Ride. Le joueur participe à une épreuve de vol inspirée des Élytres, récupère de l'énergie, évite les obstacles et choisit une Ultra-Brèche menant vers une dimension spéciale.

{% stepper %}
{% step %}
### 🌃 Explorez Ultra Mégalopole
Accédez au donjon via un portail compatible et trouvez le dispositif Ultra Warp Ride. [Guide Ultra Mégalopole](ultra_megalopolis.md).
{% endstep %}
{% step %}
### 🪽 Lancez le vol
Dirigez-vous dans le tunnel et collectez les bonus. [Guide Ultra Warp Ride](ultra_warp_ride.md).
{% endstep %}
{% step %}
### 🌀 Choisissez une brèche
L'apparence du portail et la distance parcourue influencent la destination et la difficulté.
{% endstep %}
{% step %}
### 🐾 Découvrez une rencontre spéciale
Les Ultra-Dimensions proposent un Pokémon dont les IV, attaques supplémentaires et chances de chromatique ou d'Alpha peuvent bénéficier de votre performance. [Les sept destinations](ultra_dimensions.md).
{% endstep %}
{% endstepper %}
