Le plus simple est de choisir le canal correspondant à votre situation :

| 📝 Mon problème concerne… | 📍 Où le signaler ? |
| --- | --- |
| 🐛 Un bug, un crash ou une fonctionnalité qui ne fonctionne pas | **GitHub** ou **Discord** |

## 🐛 Bug du modpack

Vous avez rencontré un **bug, un crash ou un comportement anormal** dans Cobblemon Realms ?

Le moyen privilégié pour signaler un problème reproductible est de créer une **Issue GitHub**. Un formulaire est déjà préparé afin de vous aider à fournir les informations nécessaires.

<p align="center">
<a href="https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BBug+Modpack%5D+Description+courte&body=%23%23+Type+de+signalement%0ABug+du+modpack%0A%0A%23%23+Version+de+Cobblemon+Realms%0AExemple+%3A+6.0.0%0A%0A%23%23+Version+de+Minecraft%0AExemple+%3A+1.21.1%0A%0A%23%23+Launcher%0ACurseForge+%2F+Prism+Launcher+%2F+Autre%0A%0A%23%23+Environnement%0ASolo+%2F+Serveur+d%C3%A9di%C3%A9%0A%0A%23%23+Que+s%27est-il+pass%C3%A9+%3F%0AD%C3%A9crivez+clairement+le+probl%C3%A8me.%0A%0A%23%23+%C3%89tapes+pour+reproduire%0A1.%0A2.%0A3.%0A%0A%23%23+R%C3%A9sultat+attendu%0AQue+devait-il+se+passer+%3F%0A%0A%23%23+Logs+et+captures%0AAjoutez+le+latest.log%2C+le+crash-report+et+des+captures+lorsque+cela+est+pertinent.%0A"><strong>🐛 Ouvrir un signalement de bug →</strong></a>
</p>

### 📋 Informations utiles

Pour faciliter l'identification du problème, pensez à fournir :

- 🎮 La **version exacte de Cobblemon Realms**
- 🧱 Votre **version de Minecraft**
- 🚀 Le **launcher utilisé**
- 🌍 Si le problème apparaît en **solo ou sur un serveur**
- 🔁 Les **étapes permettant de reproduire le problème**
- 🎯 Le **résultat attendu** et le **résultat obtenu**
- 📄 Le **latest.log** ou le **crash-report**, si disponible
- 📸 Des **captures d'écran ou vidéos**, lorsque cela peut aider

{% hint style="warning" %}
🔒 Ne partagez jamais de **mots de passe, jetons d'accès, identifiants privés de serveur ou informations personnelles** dans vos logs et captures.
{% endhint %}

## 📚 Problème sur le wiki

Vous avez trouvé une **erreur, une information obsolète, un contenu manquant ou une explication peu claire** ?

Dans ce cas, utilisez une **Issue GitHub dédiée au wiki**. Cela nous permet de garder une trace des corrections à effectuer.

<p align="center">
<a href="https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BWiki%5D+Erreur+ou+contenu+manquant&body=%23%23+URL+de+la+page%0ACollez+l%27URL+de+la+page+concern%C3%A9e.%0A%0A%23%23+Langue%0AFran%C3%A7ais+%2F+Anglais%0A%0A%23%23+Qu%27est-ce+qui+est+incorrect+ou+manquant+%3F%0AD%C3%A9crivez+le+probl%C3%A8me+de+documentation.%0A%0A%23%23+Correction+sugg%C3%A9r%C3%A9e%0AIndiquez+la+bonne+information+lorsque+cela+est+possible.%0A%0A%23%23+Captures+ou+r%C3%A9f%C3%A9rences%0AAjoutez+tout+%C3%A9l%C3%A9ment+permettant+de+v%C3%A9rifier+le+signalement.%0A"><strong>📚 Signaler une erreur du wiki →</strong></a>
</p>

Indiquez simplement :

- 🔗 L'**URL de la page concernée**
- 🌐 Sa **langue**
- 📍 La **section ou le passage concerné**
- ❌ Ce qui est **incorrect ou manquant**
- ✏️ La **correction proposée**, si vous la connaissez
- 📸 Toute **capture ou référence** permettant de vérifier le problème

## 💬 Besoin d'aide ?

Si vous préférez **discuter directement avec quelqu'un**, vous pouvez utiliser le salon **support feedback** sur le Discord officiel.

<p align="center">
<a href="https://discord.com/channels/272468475287437312/1361441643298820126"><strong>💬 Ouvrir le salon support feedback →</strong></a>
</p>

Pour faciliter le traitement de votre demande, essayez de **regrouper toutes les informations utiles dans un seul message** et, si possible, de ne signaler qu'un problème à la fois.

{% hint style="success" %}
<p align="center">
✨ <strong>Un bon signalement, c'est un problème clairement décrit, des étapes reproductibles et suffisamment d'informations pour permettre de le vérifier.</strong>
</p>
