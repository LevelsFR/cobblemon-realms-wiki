# 🥚 Pokémon Breeding | Cobbreeding

{% hint style="info" %}
<p align="center">
<strong>Raise the next generation of your Pokémon.</strong> Cobbreeding adds egg breeding to Cobblemon's <strong>Pasture Block</strong>, letting compatible Pokémon produce eggs while roaming around your base. This guide explains the system as used in <strong>Cobblemon Realms</strong>.
</p>
{% endhint %}

## 🌱 What Is Cobbreeding?

Cobbreeding, created by **Ludichat and Fuzuki**, extends the existing Cobblemon Pasture Block with a breeding toggle and an egg collection area. It draws inspiration from the picnic system in Pokémon Scarlet and Violet.

With breeding, you can:

- 🥚 Produce eggs from compatible Pokémon without a separate daycare.
- 🧬 Work toward desirable IVs, Natures, Abilities, moves and inheritable forms.
- ✨ Explore configurable Shiny breeding methods.
- 🏡 Build a safe breeding area around your base.

{% hint style="warning" %}
<strong>Settings may vary.</strong> Egg generation speed, Shiny odds, limits and automation depend on the configuration of your world or server. Values from the mod author's guide are not necessarily the current values on the Cobblemon Realms public server.
{% endhint %}

## 🚀 Quick Start

{% stepper %}
{% step %}
### 🏡 Place a Pasture Block

Leave enough open space **behind the block** for the Pokémon you select to appear safely.
{% endstep %}
{% step %}
### 🔘 Enable Breeding

Open the Pasture Block and use the **breeding toggle** in the top-right area of its interface. Breeding is disabled by default.
{% endstep %}
{% step %}
### 💞 Choose Compatible Pokémon

Select Pokémon from your storage. In general, they need opposite genders and a shared Egg Group. **Ditto** has special compatibility rules.
{% endstep %}
{% step %}
### 🥚 Collect and Hatch

After the configured waiting time, collect eggs from the **bottom of the Pasture Block**. Keep an egg in your **player inventory** to progress toward hatching.
{% endstep %}
{% endstepper %}
