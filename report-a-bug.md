# 🐞 Report an Issue

{% hint style="info" %}
<p align="center">
Have you found an issue in <strong>Cobblemon Realms</strong> or on the wiki? Don't worry! 🛠️<br>
Simply choose the channel corresponding to your issue so that we can identify and fix it as quickly as possible.
</p>
{% endhint %}

***

## 🧭 Where should I report my issue?

The easiest way is to choose the channel corresponding to your situation:

| 📝 My issue concerns… | 📍 Where should I report it? |
| --- | --- |
| 🐛 A bug, crash, or feature that isn't working | **GitHub** or **Discord** |
| 📚 An error or missing information on the wiki | **GitHub** |
| 💬 A question or an issue requiring discussion | **Discord** |

{% hint style="info" %}
<p align="center">
💡 <strong>Not sure?</strong> The <strong>support feedback</strong> channel on Discord remains the easiest way to ask for help.
</p>
{% endhint %}

***

## 🐛 Modpack Bug

Have you encountered a **bug, crash, or abnormal behavior** in Cobblemon Realms?

The preferred way to report a reproducible issue is to create a **GitHub Issue**. A form is already prepared to help you provide the necessary information.

### 📋 Useful Information

To make it easier to identify the issue, remember to provide:

- 🎮 The **exact version of Cobblemon Realms**
- 🧱 Your **Minecraft version**
- 🚀 The **launcher you are using**
- 🌍 Whether the issue occurs in **single-player or on a server**
- 🔁 The **steps required to reproduce the issue**
- 🎯 The **expected result** and the **actual result**
- 📄 The **latest.log** or **crash-report**, if available
- 📸 **Screenshots or videos**, whenever they may help

{% hint style="warning" %}
🔒 Never share **passwords, access tokens, private server credentials, or personal information** in your logs or screenshots.
{% endhint %}

## 📚 Wiki Issue

Have you found an **error, outdated information, missing content, or an unclear explanation**?

In this case, use a **dedicated GitHub Issue for the wiki**. This allows us to keep track of corrections that need to be made.

<p align="center">
<a href="https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BWiki%5D+Erreur+ou+contenu+manquant&body=%23%23+URL+de+la+page%0ACollez+l%27URL+de+la+page+concern%C3%A9e.%0A%0A%23%23+Langue%0AFran%C3%A7ais+%2F+Anglais%0A%0A%23%23+Qu%27est-ce+qui+est+incorrect+ou+manquant+%3F%0AD%C3%A9crivez+le+probl%C3%A8me+de+documentation.%0A%0A%23%23+Correction+sugg%C3%A9r%C3%A9e%0AIndiquez+la+bonne+information+lorsque+cela+est+possible.%0A%0A%23%23+Captures+ou+r%C3%A9f%C3%A9rences%0AAjoutez+tout+%C3%A9l%C3%A9ment+permettant+de+v%C3%A9rifier+le+signalement.%0A"><strong>📚 Report a wiki error →</strong></a>
</p>

Simply provide:

- 🔗 The **URL of the relevant page**
- 🌐 Its **language**
- 📍 The **relevant section or passage**
- ❌ What is **incorrect or missing**
- ✏️ The **suggested correction**, if you know it
- 📸 Any **screenshot or reference** that can help verify the issue

## 💬 Need Help?

If you prefer to **talk directly with someone**, you can use the **support feedback** channel on the official Discord.

<p align="center">
<a href="https://discord.com/channels/272468475287437312/1361441643298820126"><strong>💬 Open the support feedback channel →</strong></a>
</p>

To make it easier to process your request, try to **group all relevant information into a single message** and, if possible, report only one issue at a time.

{% hint style="success" %}
<p align="center">
✨ <strong>A good report is a clearly described issue, reproducible steps, and enough information to allow it to be verified.</strong>
</p>
{% endhint %}
